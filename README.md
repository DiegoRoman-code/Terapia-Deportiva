# ⚽ Terapia Deportiva

Participé en el desarrollo e implementación de [TerapiaDeportiva.cl](https://terapiadeportiva.cl/), un sitio web orientado a la publicación y difusión de contenido deportivo.

## 🛠️ Tecnologías utilizadas

- **WordPress:** administración y desarrollo del sitio web.
- **Elementor:** diseño y personalización de páginas.
- **Plugins de WordPress:** optimización del sitio, SEO y formularios de contacto.

## 💻 Mi participación

Colaboré en el desarrollo de la plataforma, participando en tareas de configuración, personalización y diseño del sitio web. Durante el proyecto, apliqué conocimientos de desarrollo web y gestión de contenidos utilizando herramientas de WordPress.
